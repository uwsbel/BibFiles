# BibFiles

The SBEL shared BibTeX collection, one topic file per subject (`refsMBS.bib`, `refsTerramech.bib`,
`refsML-AI.bib`, ...). Every lab document cites from it; see `technical/bibliography.md` in the lab wiki
for the linking convention (`\bibliography{BibFiles/refsMBS,...}`) and `compileBibRefs.py` for producing a
self-contained `refs.bib` for co-authors or a journal.

Curated reading lists kept in step with the `.bib` files:

1. `chrono-references-by-topic.md`: one or two Chrono-related papers per topic, with keys and citation
   counts; the "learn more" list for Chrono talks.
2. `terramechanics-lab-papers.md`: the lab's SCM, CRM and DEM publications from 2016 on.
